# Obsidian Legion

A pure-black website with bronze display typography, warm taupe text, and metallic bronze details for programmers, systems engineers, and system architects who want to build on their own terms.

The site is generated by **Unison**, the programming language. `src/site.u` defines the content models, shared HTML components, page composition, HTML escaping, and five executable entry points. UCM typechecks and compiles this source, then executes it to produce complete HTML documents served by GitHub Pages. CSS handles presentation; a small JavaScript file enhances the mobile menu, discipline tabs, and application form. Page navigation and reading do not require JavaScript.

## Pages

- `index.html` — compact homepage, crest, and links to each chapter.
- `ethos.html` — principles, practical habits, and collaboration standards.
- `collective.html` — disciplines, first contributions, and community discussions.
- `build.html` — software, infrastructure, and architecture project blueprints.
- `join.html` — private Legionnaire application form.

Each page has its own title, description, canonical URL, and active navigation state. Direct links and refreshes work on GitHub Pages without server rewrites. Legacy homepage fragments (`#manifesto`, `#collective`, `#build`, and `#join`) redirect to their corresponding documents when JavaScript is enabled.

## Local development

Install [Unison 1.3.0](https://github.com/unisonweb/unison/releases/tag/release%2F1.3.0) and Node.js 24, with `ucm` on your PATH.

```sh
npm run build
npm run check
npm run preview
```

Open http://127.0.0.1:4187. There are no npm dependencies to install. The first build downloads the official Unison base library and stores the project in the ignored `.ucm` directory. The build uses an isolated project codebase and does not change your personal Unison codebase.

- `src/site.u` — Unison source of truth for page content and HTML generation.
- `public/styles.css` — responsive black visual identity and reduced-motion support.
- `public/site.js` — keyboard-accessible tabs and mobile navigation.
- `public/motion.css` and `public/motion.js` — crest orbits, embers, entrances, hover lighting, and the persistent motion toggle. Motion honors the system's reduced-motion preference; the particle field stops while the document is hidden. All reading and navigation work without these enhancements.
- `public/assets/obsidian-legion-eagle.jpg` — the supplied eagle logo, preserved unchanged.
- `scripts/build.mjs` — runs the UCM transcript and copies public assets.
- `scripts/pages.mjs` — maps each public document to its Unison entry point.
- `scripts/check.mjs` — checks all pages, metadata, cross-page links, accessible controls, and signup fields.
- `.github/ISSUE_TEMPLATE/build-idea.yml` — build proposal form used by the website.

Edit the source or public assets and run the build again. Generated output is in `dist/` and is not committed.

## Deployment

The GitHub Actions workflow installs the pinned UCM runtime, compiles the Unison source, verifies the output, and publishes `dist/` to GitHub Pages on every push to `main`. Set the repository's Pages publishing source to **GitHub Actions**.

## Brand asset

The active logo is the eagle artwork supplied by the project owner. The original JPEG is preserved unchanged. `BRAND.md` documents the current identity and the earlier generated concept, which remains available in the assets directory.
## Legionnaire applications

The Unison-generated public site includes a **Become a Legionnaire** form. Applications are submitted over HTTPS to a separate persistent service because GitHub Pages does not execute server code.

- Signup: https://wolfbreed1829.github.io/obsidian-legion/join.html
- Administration: https://obsidian-legion-enlistment.littlecrowsbe.chatgpt.site/admin
- Community: https://github.com/Obsidian-Legion/community

Administration uses GitHub OAuth and a server-side allowlist of approved GitHub account IDs. Application records, private notes, and hashed admin sessions live in the service database, not this repository. Accepting an application records a decision; GitHub organization invitations remain a separate owner action.

The companion source is managed as its own Sites repository in the locally ignored `legionnaire-service/` directory. Runtime credentials are stored in Sites environment secrets. Never put OAuth secrets, applicant data, or session tokens in this public repository.
